# Switch access

Saywell's built-in scanning lets someone choose every word with one or two switches.

## Connect a switch

Most switch interfaces (for example Bluetooth "switch interface" boxes, or USB adapters) appear to
Android as a keyboard and send a key when the switch is pressed, usually **Space** and **Enter**.
Pair or plug it in as the maker describes. Saywell keeps the screen as it is when a switch connects.

## Turn on scanning

**Settings › Switch scanning › Use switch scanning**, then pick:

| Setting | Choices |
|---|---|
| Switches | **One switch**: the highlight moves by itself; press to choose. **Two switches**: one switch moves the highlight, the other chooses. |
| Scanning order | **Rows first, then buttons** (faster on big boards) or **One button at a time** (simpler) |
| Time on each step | How long the highlight stays (one switch) |
| Pause after | Rounds with no choice before scanning pauses; any press restarts it |
| Say each highlighted item | Auditory scanning: speaks the highlighted word or row |
| Tap anywhere to choose | The whole board acts as a switch, for people who can touch but not aim |

The first row scanned is the message bar: **Speak**, **Delete** and **Clear**, plus **Back** and
**Home** on other boards. Then each row of the board. In a row, after the set number of rounds
with no choice, scanning goes back to choosing rows.

## Which switch does what

**Choose switch** and **Move switch** learn the keys: tap one, press the switch, check the name
shown, then save. With one switch, any of the learned keys chooses. **Reset switch keys** restores
Space for *move* and Enter for *choose*.

Scanning only takes keys while the talking screen is showing, so typing on the keyboard screen
and editing work normally. Caregiver screens (editing, settings) are used by touch.

## Other ways in

Every Saywell button is labelled for **Android Switch Access** and **TalkBack**, so they also
work if you prefer Android's own switch scanning (Settings › Accessibility on the device).
